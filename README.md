# رحلة | Rihla

واجهة عربية من صفحتين لتحديد بحث الرحلات لدى تاركو وبدر وسودانير.

## الحالة الفعلية

أُزيلت جميع الرحلات والأسعار التجريبية. صفحات الحجز المقدمة أعادت HTTP 403 خلال فحص القراءة الآلية من GitHub Actions بتاريخ 2026-10-13. لذلك لا توجد حاليًا بيانات رحلات أو أسعار فعلية داخل الموقع، ولم يُنفَّذ تكامل بحث مع نظام Zenith.

تعرض صفحة النتائج حالة الوصول إلى مصدر كل شركة ورابط صفحة الحجز الأصلية. الروابط لا تمرر بيانات البحث؛ يجب إعادة إدخال المدن والتواريخ والمسافرين لدى الشركة.

## فحص المصادر

تتحقق دالة Vercel api/sources.js من إمكانية الوصول إلى صفحات الحجز المحددة فقط، دون استخراج الأسعار أو تنفيذ حجوزات. الاستجابة الناجحة لصفحة HTML لا تعني توفر رحلة. الأخطاء والمهلات لا تتحول إلى نتائج فارغة أو عروض تقديرية. إتاحة البحث الفعلي تتطلب مصدر بيانات يمكن الوصول إليه وتوثيقًا لنموذج الطلب والاستجابة.

## التشغيل والنشر

يستورد Vercel المستودع بإعداد Other ومجلد الإخراج dist، وينشر وظيفة api/sources.js من الجذر. لا يحتاج إلى أمر بناء أو أسرار. فتح ملفات HTML محليًا يسمح باستخدام الواجهة والروابط، لكن فحص المصادر يعمل عبر وظيفة Vercel فقط.

## التحقق

node --check dist/app.js

node --test test/sources.test.js

تشمل اختبارات الوظيفة رفض الشركات غير المعروفة، وحالة 403، والمهلات، وعدم اعتبار صفحة الحجز عروض رحلات.
